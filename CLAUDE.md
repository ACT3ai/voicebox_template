# VoiceBox Template — CLAUDE.md

## What this directory is

This directory hierarchy is the **VoiceBox template**.

* It will be a Docusaurus site, and more.
* It is the **template**: the starting point every citizen copies to create their own VoiceBox.
* It stays **nearly empty of content** on purpose. Keep it that way: structure, scaffolding, config, and placeholder pages only. Don't fill it with real broadcast content.
* Customers (citizens) change it themselves. They make the content their own: the content they broadcast publicly.
* To help edit this content (broadcast content), citizens can use any mix of:
  * their **Citizen Voice**,
  * their **Citizen Home Studio** (the local web app, Software #1 below),
  * and/or a web app running locally.

## The software citizens run

This will often be our software that citizens run.

### Software #1: Citizen Home Studio (private, localhost)

* Isolated name (alone): **Citizen Home Studio**
* Full name: **We the Citizen's Citizen Home Studio**
* A private web app the citizen runs on localhost on their own computer.
* They can do things locally, and they can approve what goes into their VoiceBox.
* They can choose things like how many videos they want to support and reshare.
* They can also create AI smart contracts of our type to do things.

### Software #2: VoiceBox (public, broadcast), which is what this template is

* Isolated name (alone): **VoiceBox**
* Full name: **We the Citizen's VoiceBox**
* Full name with an owner, for example: **Alex Castro has his "We the Citizen's VoiceBox"**
* The citizen's public web app: the public content they broadcast to the world.
* Citizens often publish new laws, plans, or other things we do here. They might publish investigations or competing hypotheses.
* It will often be Docusaurus.
* It will often be hosted somewhere lightweight, like GitHub Pages or one of many alternative hosts, ideally for about $3 a month.

## Rules for working in this template

* Build generic structure that any citizen can fill in. Never add one specific citizen's content.
* Keep it static-host friendly: it must build to static files that GitHub Pages or a cheap host can serve.
* Home Studio (private, local) and VoiceBox (public) are separate. Nothing private belongs in this template.

## Layout
* `site/` holds the Docusaurus 3 site (React 19, TypeScript). Run npm from `site/`. Docs live in `site/docs/`, and the sidebar is autogenerated from its folders (laws, plans, investigations, hypotheses). Per-citizen settings are in the CUSTOMIZE block of `site/docusaurus.config.ts`.
* `pm/` is for product management only. Never put code in it.
* `prompts/` holds AI prompt files.
* `.github/workflows/pages.yml` deploys to GitHub Pages. You can override the URL and base URL with the repo variables DOCUSAURUS_URL and DOCUSAURUS_BASE_URL.
* `onBrokenLinks` is set to "throw", so a broken internal link fails the build.
